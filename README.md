# First_project
Earthquake Data Analysis and Visualization

Developed an end-to-end Earthquake Data Analysis project using Python, Pandas, MySQL, SQLAlchemy and Streamlit to analyze and visualize earthquake data.
The project involves cleaning and processing earthquake data from a CSV dataset, storing the data in a MySQL database, and performing 28 analytical SQL queries to identify important earthquake patterns and trends.
A Streamlit web application was developed to provide where users can execute the SQL queries and view the results.
